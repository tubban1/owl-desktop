# OWL Desktop 2.0 Dependency Roadmap

Status: **Planning baseline**.

## Phase 0 — Contract freeze

Required before broad parallel implementation:

- Runtime Consumer Contract v1
- Cloud Bridge Contract v1
- platform identity/event conventions
- compatibility/version policy

## Phase 1 — Local shell

Develop in parallel with Runtime 1.0 release evidence:

- OWL MCP compatibility adapter
- RuntimeClient backend
- local Control Panel shell
- stable installer/update model
- Runtime/Helper/Host status surfaces

No new Runtime logic is implemented here.

## Phase 2 — Cloud Bridge

After Cloud Contract v1 is stable:

- device registration
- grant validation
- presence heartbeat
- command channel
- command idempotency
- result/receipt projection
- reconnect/offline behavior

## Phase 3 — Local E2E

```text
ChatGPT → OWL MCP → OWL Runtime → Mac
```

Legacy backend remains explicit rollback only; never silent fallback.

## Phase 4 — Cloud E2E

```text
test client / Worker → OWL Cloud → Cloud Bridge → Runtime → result projection
```

Worker UI is not required to prove the Cloud E2E contract.

## Phase 5 — OWL Desktop 2.0 candidate

Requires:

- compatibility matrix
- install/update/rollback
- local E2E
- cloud E2E
- reconnect tests
- permission identity stability
- dogfood/soak
